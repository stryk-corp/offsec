Choose your platform


Kali runs on bare metal, virtual machines, small boards, phones, the cloud, containers and Windows. Pick the one that fits how you work, then follow its documentation.




Installer Images
  • Direct access to hardware
  • Customized Kali kernel
  • No overhead
Single or multi-boot Kali with full hardware control, ideal for built-in Wi-Fi and GPUs.


Virtual Machines
  • Snapshots
  • Isolated environment
  • Limited hardware access
  • Higher system requirements
VMware, VirtualBox, Hyper-V and QEMU images, plus Vagrant boxes for quick spin-up.


ARM
  • From leave-behind devices to servers
  • Some packages limited by architecture
Runs on low-power single board computers and modern ARM laptops.


Mobile
  • Kali layered on Android
  • Kali in your pocket
  • Compact mobile interface
NetHunter app, app store, Kali container and KeX for supported devices.


Cloud
  • Fast deployment
  • Use the provider's resources
  • Can become costly
Ready-to-go Kali on AWS, Azure, Linode and DigitalOcean.


Containers
  • Low overhead toolset access
  • Userland actions only
  • No direct hardware access
Docker and LXC/LXD for quick access without a full virtual machine.


Live Boot
  • Host system untouched
  • Direct hardware access
  • Slower under heavy I/O
Run a full Kali from USB, DVD or PXE without installing anything.


WSL
  • Toolset inside Windows
  • Win-KeX desktop
  • Userland actions only
Use Kali alongside Windows with the Windows Subsystem for Linux.




Build scripts for every image are public on GitLab, so you can read, audit and change how Kali is built.
